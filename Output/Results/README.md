# Results Folder

## Overview

The `Results` folder stores the canonical analytical products generated by the data cleaning and C/IER screening notebooks (`Scripts/ProcessingScripts/`). These outputs represent the published findings embedded directly into the main Quarto Manuscript (`index.qmd`).

## Subdirectories and File Inventory

### 1. `Figures/` (`Output/Results/Figures/`)
Stores all canonical publication plots in high-resolution PNG format, generated by `02_posthoc.qmd`:

| File Name | Chunk / Label | Description |
|---|---|---|
| `fig-viz-lazr.png` | `#fig-viz-lazr` | Univariate distribution (histogram + boxplot) of Laz.R indicator |
| `fig-viz-longstr.png` | `#fig-viz-longstr` | Univariate distribution of Longstring indicator |
| `fig-viz-md.png` | `#fig-viz-md` | Univariate distribution of Mahalanobis Distance (MD) indicator |
| `fig-viz-irv.png` | `#fig-viz-irv` | Univariate distribution of Intra-individual Response Variability (IRV) |
| `fig-cum-lazr.png` | `#fig-cum-lazr` | Cumulative Laz.R curve with Kneedle cut-off point |
| `fig-cum-longstr.png` | `#fig-cum-longstr` | Cumulative Longstring curve with Kneedle cut-off point |
| `fig-cum-md.png` | `#fig-cum-md` | Cumulative Mahalanobis Distance curve with Kneedle cut-off point |
| `fig-cum-irv.png` | `#fig-cum-irv` | Cumulative IRV curve with dual Kneedle cut-off points (low & high) |

### 2. `Tables/` (`Output/Results/Tables/`)
Stores all canonical published tables in standard semicolon-delimited CSV format (`readr::write_csv2()`):

| File Name | Chunk / Label | Generating Script | Description |
|---|---|---|---|
| `tbl-level-1-summary.csv` | `#tbl-level-1-summary` | `01_procedural.qmd` | Procedural exclusions summary across Level 1 criteria |
| `tbl-kneedle-cutoffs.csv` | `#tbl-kneedle-cutoffs` | `02_posthoc.qmd` | Estimated cut-off points from the Kneedle algorithm |
| `tbl-flags-overview.csv` | `#tbl-flags-overview` | `02_posthoc.qmd` | Counts and percentages of respondents flagged per indicator |
| `tbl-decision-scenarios.csv` | `#tbl-decision-scenarios` | `02_posthoc.qmd` | Cross-comparison of multi-indicator exclusion scenarios |
| `tbl-flag-pairwise-overlap.csv` | `#tbl-flag-pairwise-overlap` | `02_posthoc.qmd` | Pairwise co-occurrence and overlap among C/IER flags |
| `tbl-lazr-md-intersection.csv` | `#tbl-lazr-md-intersection` | `02_posthoc.qmd` | 2x2 contingency matrix of Laz.R vs. Mahalanobis Distance flags |
| `tbl-posthoc-exclusion-patterns.csv` | `#tbl-posthoc-exclusion-patterns` | `02_posthoc.qmd` | Empirical indicator combinations among excluded respondents |
| `tbl-analysis-sample-summary.csv` | `#tbl-analysis-sample-summary` | `02_posthoc.qmd` | Final sample composition before and after C/IER exclusions |

## Guidelines

- All files in this folder are reproducible and programmatically generated.
- Changes to analytical parameters, thresholds, or code will automatically regenerate these files upon running `quarto render`.
- During compilation, `Scripts/DataAppendixScripts/post_render_figures.R` and `post_render_tables.R` dynamically mirror these assets to `docs/Output/Results/` for web publication.
